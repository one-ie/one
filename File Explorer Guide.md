## ⚡ Quick Actions

1. **Open any file**: Just click the link!
2. **Edit code**: VSCode editor opens automatically
3. **Preview**: Some files show preview on hover
4. **Search**: Use `Cmd+Shift+F` to search content

## 🔍 Find Files Fast

Use these patterns in Quick Switcher (`Cmd+O`):
- `.env` - Find env files
- `.ts` - Find TypeScript files  
- `config` - Find config files
- `.` - Show ALL dotfiles
