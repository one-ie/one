
**Course Module Structure Table 

| #   |                | Component Name                   | Format(s)                          | Purpose                                                                                  | Key Content / Integration Notes                                                                                                                                                                                      |
| --- | -------------- | -------------------------------- | ---------------------------------- | ---------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | intro          | Introduction                     | Text                               | Set context, state objective, explain importance of this step.                           | Clear Title (Module #, Step Name), Objective Statement, Brief Overview linking to previous/next steps.                                                                                                               |
| 2   | video script   | **Core Concept Explanation**     | Primary Video Lesson, Support Text | Teach the underlying strategy, principles, and psychology of the step.                   | Explain step's core concepts, connect to **Foundation**, introduce AI's role, include screen-share AI prompt demos. Text summarizes video keys.                                                                      |
| 3   | grid           | **3x3 Grid for This Step**       | Visual Graphic, Text Explanation   | Provide a structured visual framework for thinking about & executing the step.           | Display the step-specific grid (e.g., HOOK Grid, GIFT Grid). Explain quadrants and how **Foundation** inputs inform it. Downloadable/printable.                                                                      |
| 4   | checklist      | **Actionable Task Checklist**    | Text List, Downloadable Worksheet  | Guide the student through the exact implementation tasks required for this step.         | Sequential, checkable list of actions (e.g., "Review X", "Run Prompt Y", "Draft Z", "Implement on Platform").                                                                                                        |
| 5   | prompts        | **AI Prompt Playbook Section**   | Text, Links/Embeds                 | Provide the specific, relevant AI prompts from the Playbook for this step's tasks.       | List core prompts for this step. Include usage guidance, required **Foundation** context inputs, "Copy Prompt" button if possible. Emphasize *refinement*. only list the prompt title dont actually write the prompt |
| 6   | worksheet      | **Worksheet(s) / Templates**     | Downloadable, Interactive Form     | Offer practical tools to structure inputs or outputs for the step's activities.          | Examples: Foundation Grids, Hook Rating Sheet, Email Sequence Planner, Sales Page Outline. Keep simple and focused.                                                                                                  |
| 7   | examples       | **Output Definition & Examples** | Text, Visual Examples              | Clearly define the expected tangible deliverables for the module and provide benchmarks. | State specific outputs (e.g., "5 headlines", "draft sequence"). Show 1-2 concrete visual/text examples of "good" quality output (can be templates or anonymized examples).                                           |
| 8   | implementation | **Implementation Guidance**      | Text, Optional Short Video         | Bridge the gap between AI-generated drafts and real-world application. "Now What?".      | Explain *exactly where* and *how* to manually implement the refined assets (Ads Manager, ESP, Website CMS etc.). Include implementation best practices (A/B testing, formatting).                                    |
| 9   | transition     | **Module Summary & Transition**  | Text                               | Recap key achievements and logically connect to the next step in the framework.          | Summarize key learnings/outputs. Reinforce contribution to overall framework. Clearly state the *next* module/step and how this one prepares for it.                                                                 |
| 10  | chapter        | Chapter for the book             | Text                               | For our book                                                                             | Write this book chapter                                                                                                                                                                                              |
