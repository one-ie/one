## 🚀 Workflow Commands

**`/now`** - What you're working on right now
- Shows current inference (Infer 5/100)
- Displays task description and context
- Lists next 5 inferences in sequence

**`/next`** - Advance to next task in sequence
- Skips current inference if not applicable
- Loads context for next task automatically
- Updates progress tracker

**`/todo`** - View your complete task list
- 100-inference sequence for current feature
- Filter by dimension (organizations, people, things, connections, events, knowledge)
- Filter by specialist (backend, frontend, integration, quality, design)

**`/done`** - Mark current task complete
- Marks inference complete in state
- Captures lessons learned
- Advances to next inference
- Updates progress (currently 4/100 = 4%)

## ⚙️  Creation Commands

**`/build`** - Build features with AI specialists
- Backend Specialist: Services, mutations, queries, schemas
- Frontend Specialist: Pages, components, UI/UX
- Integration Specialist: Connections, data flows, workflows

**`/design`** - Create wireframes & UI components
- Design Agent creates wireframes that enable tests to pass
- Component architecture (atoms, molecules, organisms)
- Design tokens (colors, spacing, timing, accessibility)

**`/deploy`** - Ship to production
- Build production bundle
- Deploy backend to Convex Cloud
- Deploy frontend to Cloudflare Pages
- Run smoke tests

## 👁️  Insight Commands

**`/see`** - View analytics, refine vision, explore courses
- **Analytics:** Command usage, workflow patterns, success rates
- **Vision:** Refine your ideas with AI-powered insights
- **Courses:** Explore educational content, recommended learning paths
- **Documentation:** Semantic search across all docs
