## What the chat can do

```
   ┌─────────────────────────────────────────┐
   │  ✏️  write a new page or blog post       │
   │  ✏️  edit an existing one                │
   │  ✏️  delete one (undo always works)     │
   │  📋  list everything you've written      │
   │  🔍  read a URL and summarize it for you│
   └─────────────────────────────────────────┘
```

That's it. No "build a custom React component." No "deploy a database." No "configure your DNS." If it isn't on this list, it's not in your way.

---

## What the chat cannot do

```
   ┌─────────────────────────────────────────┐
   │  ✗  edit your site's code               │
   │  ✗  change the layout or design         │
   │  ✗  touch anyone else's site            │
   │  ✗  write without your face             │
   └─────────────────────────────────────────┘
```

The code stays under our roof. Updates ship to everyone at once — when we make the chat smarter, your site gets smarter the same second.

You're reading your /pricing page. You spot a typo. You don't open the chat. You don't fly through menus. There's a small ✏️ in the corner — only *you* can see it.

## Identity, the easy way

Your site belongs to your face.

```
   ┌─────────────┐         ┌──────────────┐
   │   your face │ ──────▶ │  your device │
   │  fingerprint│         │  secure chip │
   │     PIN     │         │              │
   └─────────────┘         └──────────────┘
                                  │
                                  │  signs each edit
                                  ▼
                           ┌──────────────┐
                           │   one.ie     │
                           │  verifies    │
                           └──────────────┘
```

No password to forget. No email to lose access to. New phone? Sign in with your face. All devices lost? You wrote down 12 recovery words at the start — they bring it back.

This isn't a metaphor. The private key never leaves your device. Even we cannot read your site as you.
